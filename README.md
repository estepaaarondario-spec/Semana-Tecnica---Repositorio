# 🌸 Semana Técnica

Página interactiva en rosa pastel para guardar links y recursos de la Semana Técnica.

## Cómo publicarla en GitHub

1. Creá un repositorio nuevo en GitHub (por ejemplo `semana-tecnica`).
2. Subí `index.html` y `README.md` a la raíz del repositorio.
3. Andá a **Settings → Pages**.
4. En **Source** elegí **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
5. Guardá. En un minuto tu página estará en `https://TU-USUARIO.github.io/semana-tecnica/`.

## Cómo usarla

- **Agregar:** completá título, link y categoría, y tocá *Guardar*.
- **Editar / Borrar:** con los botones de cada tarjeta.
- **Filtrar:** por categoría o con el buscador.
- **Exportar / Importar:** descargá tus links en un archivo `.json` para hacer copia o pasarlos a otra computadora.

## Importante

Los links se guardan en el navegador de quien usa la página (`localStorage`). Cada persona ve sus propios links; no se comparten automáticamente entre visitantes. Para compartir una lista, usá *Exportar* y pasale el archivo a otra persona para que lo *Importe*.
